# 🎒 幼小衔接学习工作台 v2

面向 5~7 岁幼小衔接儿童的轻量化学习工作台：**六大学习模块 + 学习豆打卡体系 + 积分商城 + 学习数据中心**。界面卡通低龄友好，手机/平板/电脑都能用，可放到手机桌面像 App 一样使用。

## 🌍 永久地址

**https://yby432.github.io/youxiao-workbench/**

手机打开后：安卓 Chrome 菜单「安装应用」/「添加到主屏幕」，苹果 Safari 分享「添加到主屏幕」。

## ✨ 六大学习模块

| 模块 | 内容 |
|------|------|
| 🀄 **识字** | 300 字字库按单元分组（虚拟人教版结构）、单字状态机（未学→已学→已掌握）、随堂练习、**生字听写**、**生字闪卡**、薄弱字本自动归集、识字量看板 |
| 🔤 **拼音** | 声母/韵母/整体认读音节表、每日两拼练习、**三拼练习**、拼音闯关游戏 |
| 🏮 **古诗** | 60 首部编版必背古诗每日轮换、朗读、**收藏**、**背诵打卡**（联动任务） |
| 🗣️ **英语** | 26 字母卡、15 主题单词、每日 5 短句（全部可点读跟读）、英文儿歌磨耳朵、入门/基础分级 |
| 🔢 **数学** | 20 以内口算（凑十/破十）、数感星球、思维训练、**认识钟表**（canvas 钟面出题）、**图形认知**、错题复习本 |
| 🪐 **科普** | 40 条图文问答（天文/动物/植物/生活/安全/自然现象），每日轮换 + 按分类浏览 |

另有休闲模块：🏃 运动（跳绳计时 + 前庭训练）和 🎮 趣味游戏（拼音对对碰闯关、抓大鹅）。

## 🪙 学习豆打卡体系

- 每日 6 个固定任务，**每完成一个即时得豆**：识字+5 / 拼音+4 / 古诗+3 / 英语+4 / 数学+5 / 科普+2（家长可自定义）
- **连续打卡** 3/7/30 天额外奖励学习豆
- **打卡日历**：绿=完成、黄=部分、灰=未打卡；漏卡可用豆子**补打卡**保连续
- **积分商城**：低/中/高三档 12 件奖品，兑换记录 + 收货地址备注（家长可在家长中心增删改奖品）
- **数据中心**：识字量看板、近 7 天掌握曲线、打卡趋势、薄弱字本、薄弱项提示、兑换记录
- **家长中心**：防沉迷时长设置、任务管理、奖品管理、数据导出/导入备份
