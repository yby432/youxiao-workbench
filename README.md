# 🎒 幼小衔接工作台

专为 5~7 岁幼小衔接阶段设计的儿童学习工作台。像 App 一样的界面，可放到手机桌面使用。

## ✨ 功能一览

| 模块 | 内容 |
|------|------|
| 📖 **语文**（每日 30 分钟） | 每日古诗（60 首轮换）、成语故事（46 个轮换）、每日 5 个新字（300 字池轮换）、控笔训练（可打印练习纸 + 可粘贴抖音跟练视频）、拼音拼读练习、每日绘本推荐（30 本轮换） |
| 🔢 **数学** | 20 以内口算（凑十法 / 破十法 / 直接算，可选题型题数）、数感星球（比大小/分成/相邻数/单双数）、思维训练（找规律/比轻重/排队问题）、**错题复习本**（做错的题自动收集，可重练/删除） |
| 🗣️ **英语** | 每日 5 条日常交流短句 + 每日 8 个单词（15 主题轮换），全部**可点读跟读**（浏览器朗读） |
| 🏃 **运动**（每日 20 分钟） | 跳绳 10 分钟计时器 + 计数、前庭训练小活动（30 种，**刷新按钮随时换**） |
| 🎮 **游戏** | 🔤 拼音文字对对碰（闯关赢星星）、🦢 抓大鹅（水果 emoji ↔ 英文单词配对消除） |
| ⭐ **奖励** | 每日全部任务打卡 +1 积分；10 分小零食 / 20 分小玩具 / 30 分儿童乐园（**档位可编辑、新增、删除**） |
| ⚙️ **设置** | **新增/删除任务**、隐藏内置任务、编辑奖励档位、控笔视频链接、数据导出备份 |

所有「每日更新」内容按日期自动轮换，也可点「🔄 换一组」手动切换。

## 🚀 启动方法

```bash
cd youxiao-workbench
node server.js          # 默认端口 8080
node server.js 3000     # 指定端口
```

启动后终端会打印：
- 本机访问地址：`http://localhost:8080`
- **手机访问地址**：`http://<电脑局域网IP>:8080`（如 `http://192.168.1.110:8080`）
- 二维码（安装了 qrcode 后显示，手机扫码直接打开）

### 备用：免费临时公网隧道（Cloudflare Quick Tunnel）

```bash
cd youxiao-workbench
.\tools\cloudflared.exe tunnel --url http://localhost:8080 --no-autoupdate
```

启动后终端会打印一个 `https://xxxx.trycloudflare.com` 地址。注意每次重启地址都会变，适合临时应急，不适合长期使用。

## 📱 放到手机桌面（核心功能）

1. 手机和电脑连接**同一个 WiFi**
2. 手机浏览器打开终端打印的「手机访问」地址（或扫二维码）
3. **安卓（Chrome）**：右上角 `⋮` → 「添加到主屏幕」/「安装应用」
4. **苹果（Safari）**：底部分享按钮 → 「添加到主屏幕」
5. 手机桌面就会出现工作台图标，点开像 App 一样全屏使用

> 数据保存在浏览器本地（localStorage），换设备/清缓存会丢失，可在「设置 → 导出备份」保存。

## 🛠️ 常见问题

- **手机打不开？** 确认手机与电脑同一 WiFi；如仍不行，可能是 Windows 防火墙拦截了 8080 端口，放行即可（或换用已放行的端口）。
- **没有朗读声音？** 需要设备支持 TTS 语音（安卓/iOS 均有），首次使用可在系统设置中安装中文/英文语音包。
- **控笔跟练视频**：在「设置」里粘贴抖音/任意教学视频链接，语文页就会出现「打开跟练视频」按钮。
- **想公网访问？** 本应用是完整 PWA（含 manifest + service worker），部署到任意 https 静态托管（Vercel/Netlify/Cloudflare Pages）即可获得完整离线能力。

## 📁 目录结构

```
youxiao-workbench/
├── index.html          # 入口页面
├── manifest.json       # PWA 清单
├── sw.js               # Service Worker（离线缓存）
├── server.js           # 本地静态服务器
├── gen-icon.js         # 图标生成脚本
├── smoke.js            # 冒烟测试脚本（node smoke.js）
├── assets/             # PWA 图标
├── css/style.css       # 样式
└── js/
    ├── data.js         # 内容数据池（古诗/成语/汉字/英语/前庭/绘本/水果）
    ├── pinyin.js       # 拼音数据 + 拼读/对对碰题目生成
    ├── math-gen.js     # 数学题生成（口算/数感/思维）
    ├── core.js         # 状态存储 / 打卡积分 / 导航
    ├── app.js          # 首页 / 语文 / 数学 / 英语 / 运动
    ├── games.js        # 两个闯关游戏
    └── extras.js       # 奖励柜 / 设置 / 初始化
```
